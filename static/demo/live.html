接入面 · 五种接入方式，同一个引擎

每一条都从仓库检出直接跑：claude mcp add 一行、jsonmend serve 一个长驻进程、两个语言包按仓库路径安装。npm 与 PyPI 上的 jsonmend 名字已被无关项目占用，本仓库的包名是 jsonmend-moonbit，尚未发布到任何注册表，所以下面写的是仓库路径。

安全默认：库默认 permissive（显示通道该尽量修）；任何执行路径必须显式传 profile="agent" 或 "execution"，否则这道门只是建议。
