repair · analyze · 五种安全档位

22 条修复规则

R001–R022 · 单次左到右扫描

每条规则都能当场触发：点「试用」把它自己的样本送进工作台，修复记录里就会出现这条码。 规则在单次从左到右扫描中即时生效，不回溯、不二次遍历；同一位置可能命中多条，按扫描顺序各产生一条记录（实现按扫描顺序登记，不按编号重排）。 Info 只改记法（Cosmetic），Warning 发明或丢弃了信息（Lossy）。

字段就绪曲线

watch_readiness · ReadinessEvent

每个声明过的成员在输入消耗到多少时定稿，是一次事件流而不是离线测量。 field_ready / field_invalid / field_rejected / root_ready / root_invalid 都在值定稿的那个 delta 上发出， 所以「值不对」可以在流还没结束时就被拒绝，从而取消整次生成。

六种接入方式

MCP · stdio · npm · pip · HTTP · MoonBit

这一页为什么可信
  • 输出必合法 JSON · 修复幂等 · 任意分块与一次性结果一致 · 快照是稳定前缀 · 任何字节序列不 panic。
