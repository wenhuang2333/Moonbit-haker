InterJSON × MCP — 执行门接入

MCP 让 agent 发现工具；真正的价值是宿主在执行工具参数之前过闸。 interjson_gate 返回 executable；为 false 时把 retry.prompt 原样回灌模型。服务本地运行、只读、无网络。

演示目录 · 流式执行门 · GitHub · 接入说明

1. 一行配置

Claude Code

claude mcp add interjson -- interjson mcp

mcp.json（Cursor / Cline / Windsurf 等）

{"mcpServers":{"interjson":{"command":"interjson","args":["mcp"]}}}

装 pip 包时命令是 interjson-mcp（它解析二进制并替换进程）； npm 包 interjson-moonbit 的 bin 也是 interjson-mcp， 需要本机原生可执行文件。四个工具：interjson_gate（主入口，默认 agent 档） / interjson_repair / interjson_validate / interjson_readiness， 每个都只读，并同时返回文本与 structuredContent。

不想记命令：interjson mcp --print-config=claude 直接打印上面那行， --print-config=json 打印 mcpServers 片段；另外支持 cursor / vscode / codex / windsurf / zed。
